Documentation & FAQ

How does AI Research Gap Finder work?
The system uses high-density PDF parsing and vector embeddings in ChromaDB with hybrid retrieval. Multi-layer RAG cross-references explicit claims against page numbers and detects research opportunities.
Why do I need to enter my own Groq API key?
Using your own free Groq API key prevents rate limiting and ensures unlimited access across high-speed models (e.g. LLaMA 3.3 70B, Mixtral 8x7B) without consuming shared system credits.
Is my research data and API key secure?
Yes. Your API key and uploaded papers are stored securely in your private workspace and are never shared, logged, or visible to other users.
